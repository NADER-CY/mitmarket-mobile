# نصب نسخه موبایل MITMARKET

این بسته مستقل از سایت دسکتاپ است. نصب را روی یک زیردامنه جدا مثل mobile.example.com انجام دهید.

نیازمندی: Ubuntu، Nginx و Python 3. این خروجی استاتیک است و برای اجرا به Node یا npm نیاز ندارد.

۱. فایل ZIP را روی سرور آپلود و استخراج کنید.
۲. رکورد DNS زیردامنه را به سرور وصل کنید.
۳. داخل پوشه استخراج‌شده اجرا کنید:

```bash
sudo bash install-mobile.sh mobile.example.com
```

به‌جای mobile.example.com دامنه موبایل خود را بنویسید. سپس HTTPS همین زیردامنه را در تنظیمات سرور فعال کنید.

نصاب نسخه‌ها را در /var/www/mitmarket-mobile/releases نگه می‌دارد و سایت دسکتاپ را تغییر نمی‌دهد.

داده‌های عمومی بازار و نمودار از Polymarket دریافت می‌شوند و قیمت اسلایدرها و کارت‌های متصل با WebSocket به‌روز می‌شود. دسترسی شبکه سرور/مرورگر به gamma-api.polymarket.com، clob.polymarket.com و ws-subscriptions-clob.polymarket.com لازم است.

صفحه ترید شامل اطلاعات بازار، نمودار واقعی، انتخاب YES/NO، نوع سفارش و محاسبه تخمینی است. ثبت سفارش واقعی، ورود، موجودی کیف پول و سایر خدمات حساب هنوز بک‌اند ندارند. بخشی از اطلاعات ثابت طرح مرجع همچنان نمونه است.
